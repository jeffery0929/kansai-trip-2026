# 大阪・京都互動旅行規劃

直接開啟網站：https://jeffery0929.github.io/kansai-trip-2026/

## 功能

- 2026/10/20–10/28 九天行程：拖曳換日、調整順序、復原與固定訂位保護。
- 大阪／京都天氣更新及帶有時間標示的離線快照。
- 當日地圖、旅館出發與前一站出發的 Google Maps 導航。
- 39 家餐廳、13 種分類；預設價格 60%、口碑 40% 的可調整 CP 比較。
- 大阪票券試算、機場與京都交通說明、詳細行程與備案。
- 瀏覽器自動保存、HTML 快照下載、JSON 備份與匯入、CSV 匯出和列印。

## 保存與同步

此網站是純靜態網頁。調整會保存在目前裝置的瀏覽器中，不會自動提交到 GitHub，也不會同步至另一台裝置或修改 Google Maps 收藏清單。

換裝置或分享自己的修改時，請使用「備份 JSON／匯入備份」，或下載調整後的完整 HTML。

天氣、地圖底圖與導航需要網路。交通費與餐廳資料附查核依據；價格、營業時段及車次以出發時官方資訊為準。

## GitHub Pages

發布來源：`main` 分支的根目錄 `/`。首頁為 `index.html`，`.nojekyll` 表示直接提供靜態檔案。

不需要安裝套件、編譯、API key 或登入即可查看網頁。更新 `index.html` 並提交後，GitHub Pages 會重新發布。

本 repo 與網頁為公開內容，包含行程日期、飯店地址、航班與餐廳預約時間。首頁加入搜尋引擎 `noindex` 提示，但這不是存取控制。
